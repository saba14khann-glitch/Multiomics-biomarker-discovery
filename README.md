# Multi-Omics Biomarker Discovery

Explainable machine learning for cancer biomarker discovery using TCGA data.

## Goal
Identify genes that help predict breast cancer outcomes, and explain
why the model makes each prediction.

## Planned Workflow
1. Data collection (TCGA-BRCA)
2. Cleaning and exploration
3. Machine learning models
4. Explainability with SHAP
5. Interactive dashboard

## Status
🚧 In progress: currently learning and setting up the pipeline.

## Tools
Python, pandas, scikit-learn, SHAP, Streamlit
